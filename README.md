# Sistema de Gerenciamento de Biblioteca

## Sobre o projeto

Sistema de gerenciamento de biblioteca desenvolvido em JavaScript com Node.js como atividade avaliativa do curso SCTEC.

## Funcionalidades

- Listar todos os livros.
- Buscar livro pelo título.
- Listar livros disponíveis.
- Cadastrar novos livros.
- Realizar empréstimos.
- Registrar devoluções.
- Exibir estatísticas da biblioteca.

## Tecnologias utilizadas

- JavaScript
- Node.js
- prompt-sync
- Git e GitHub

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute `npm install`.
4. Execute `npm start`.

## Observação

Os dados cadastrados ficam em memória e são reiniciados quando o programa é encerrado.
